Bugs Críticos Corregidos
  • 💥
    Error React removeChild — pantalla en blanco al abrir IA
    Al hacer clic en cualquier botón de IA, la app se bloqueaba con un error de React (removeChild). Causado por extensiones del navegador (Google Translate) que modificaban el DOM entre renders.
    Solución: translate="no" en la etiqueta <html> del index.html, useRef + innerHTML en lugar de dangerouslySetInnerHTML, y ErrorBoundary en App.jsx.
  • 📊
    Porcentaje de Saludo mostrando 0.436% en vez de 43.6%
    AVG(saludo_inicial) devuelve un decimal entre 0 y 1. Se estaba mostrando directamente sin multiplicar por 100.
    Antes: 0.436% → Ahora: 43.6%
    Archivo: back/api/routes.py — agregado * 100 a los 7 indicadores del scorecard.
  • 🤝
    SALUDO OK demasiado bajo (25.4% real vs 48.8% esperado)
    17,491 de 34,974 llamadas no tienen transcripción y su saludo_inicial = 0 por defecto, bajando el promedio artificialmente. El equipo confirmó que prácticamente todos los asesores saludan.
    Antes: 25.4% → Ahora: 48.8%
    Solución: SAFE_DIVIDE filtrando solo llamadas con transcripción (LENGTH > 50). Archivo: back/api/charts/kpi.py.
  • 🗂️
    Error React #31 — Reporte Completo crash al generar
    El campo hallazgos devuelto por la IA era un array de objetos {llamada, comentario} en vez de un array de strings. React no puede renderizar objetos directamente → pantalla en blanco.
    Solución: Prompt del backend corregido para exigir strings. Archivo: back/api/routes_new.py.
  • 🔗
    Resumir Llamadas — error 404 al consultar
    El endpoint estaba mal construido: llamaba a /api/resumir_llamada sin el parámetro id en la URL.
    Corrección: URL cambiada a /api/resumir_llamada/{id}.
  • 📐
    Warnings de Recharts — altura en porcentaje sin contenedor definido
    ResponsiveContainer con height="100%" sin un padre con altura fija generaba warnings en consola y gráficas que no renderizaban.
    Solución: Alturas fijas en píxeles en los contenedores padre.

Funcionalidades Nuevas
  • 🤖
    Chat del Agente IA responde de forma conversacional
    Antes el chat devolvía tablas HTML oscuras incluso para saludos simples. Se cambió el system prompt del backend para respuestas en texto plano, sin HTML ni markdown. Ahora responde de forma natural como un asistente real. Archivo: back/api/chat.py.
  • 🔗
    Todos los botones IA conectados a los filtros activos del sidebar
    Los botones de análisis IA ignoraban los filtros del dashboard. Ahora todos pasan los filtros activos al backend usando buildQuery() del contexto global.
    const params = buildQuery(); const query = params ? `?${params}` : ''; fetch(`${API_BASE}/ia/endpoint${query}`);
    Aplica a: InsightsCard, MetricasGrid, Inteligencia, Analisis, Rendimiento.
  • 🛡️
    Protección contra errores de extensiones del navegador
    ErrorBoundary en App.jsx evita que un error en un componente borre toda la pantalla. translate="no" en el HTML previene que Google Translate modifique el DOM y rompa React.

Complementos — 19 Jun 2026
  • 🔄
    Pipeline V4 integrado en producción — 36,969 llamadas procesadas
    Se integró el motor estructurar_dialogo() en el pipeline diario subir_datos.py. Ahora cada llamada genera automáticamente Transcripcion_V4 con turnos diferenciados por hablante ([Asesor] / [Cliente]), además de detectar el campo Asistencia con un catálogo de 35+ servicios específicos de CL Tiene. La duración se calcula desde el campo real Tiempo de Conversacion del SQL Server (HH:MM:SS) en lugar de la longitud del texto.
  • ✅
    Columna "Ventas" oculta en Scorecard cuando el filtro es Servicio
    En la tabla de indicadores por asesor (Inteligencia Operativa), la columna Ventas desaparece automáticamente cuando el usuario activa el filtro "Tipo de Llamada = Servicio", manteniendo coherencia con el resto del dashboard que ya ocultaba otros elementos de ventas.
  • ⚡
    Keep-alive ping + reconexión automática al volver a la pestaña
    El frontend ahora envía un ping al backend cada 9 minutos mientras la pestaña está abierta, evitando que Cloud Run apague el contenedor por inactividad (cold start). Además, al volver a la pestaña después de 5+ minutos, se muestra un banner "Reconectando..." y se recargan los KPIs automáticamente usando la Page Visibility API del navegador.
  • 🔍
    Fix filtro "Asistencia Mencionada" — resultados correctos
    El filtro de asistencia estaba usando LIKE 'valor%', que fallaba cuando el servicio no era el primero en la lista separada por comas. Se corrigió a LIKE '%valor%' y el dropdown ahora usa UNNEST(SPLIT(Asistencia, ', ')) para mostrar cada servicio por separado sin duplicados.
  • ✅
    Filtros del sidebar conectados al análisis por asesor
    El análisis individual de cada asesor ahora respeta los filtros activos del dashboard (fechas, tipo de llamada, módulo, etc.) al consultar la inteligencia artificial.
  • ✅
    Indicadores de color por rendimiento en % Ventas
    La columna % Ventas en la tabla de asesores ahora muestra colores según el nivel: gris = sin ventas, rojo = bajo (<2%), naranja = medio (2–5%), verde = buen rendimiento (≥5%).
  • 📄
    CLAUDE.md — memoria de contexto entre sesiones
    Se creó el archivo CLAUDE.md en la raíz del proyecto. Se carga automáticamente en cada nueva sesión de desarrollo con Claude Code, manteniendo el estado del proyecto, patrones de código establecidos, fixes importantes y tareas pendientes actualizadas.
